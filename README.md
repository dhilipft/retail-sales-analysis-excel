
# Retail Sales Analysis using Microsoft Excel

## Project Overview
An end-to-end retail sales analysis project using Microsoft Excel to analyse sales performance and generate business insights.

## Objectives
- Clean and prepare raw sales data.
- Calculate revenue and key performance indicators.
- Analyse product, category and city performance.
- Build PivotTables and PivotCharts.
- Create an interactive sales dashboard.

## Tools Used
- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Slicers

## Project Workflow
1. Data Cleaning
2. Sales Calculations
3. Business Analysis
4. PivotTable Analysis
5. Dashboard Development
6. Data Verification

## Key Results
- Total Revenue: ₹2,59,500
- Total Orders: 12
- Average Order Value: ₹21,625
- Highest Order Value: ₹90,000
